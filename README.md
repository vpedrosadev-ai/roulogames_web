# ROULOGAMES

Two browser games:

- MANGOless game
- Impostor GAME

## Development

```powershell
npm install
npm run dev
```

## Cloudflare Pages

```powershell
npm run cloudflare:pages:build
```

Use `public` as the build output directory. See `CLOUDFLARE_DEPLOY.md` for D1 setup and deploy notes.
